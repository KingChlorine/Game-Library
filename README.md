# Game-Library
Game Library for tracking game collection across different platforms

I was in CEX looking at PS2 games. I wanted to buy one but wasn't sure if I already had it. I could check ebay history to see if I had bought it online, I could check PSN account to see if I had a digital copy of a remastered version but on this occassion I just put the game back because I couldn't remember if I had it, or had only been thinking about buying it. 

One of my assignments from my computing access course was to program an inventory tracker with Python. I thought this could be adapted to keep track of all my games in one place. I also thought mySQL might come in handy to store the data.

The end goal is to have an app to store my game collection, filter games to different categories and imclde search feature that accounts for misspells. I'd also like to pull data from websites to see more info about the games, check prices and verify that the game does exist before it can be added to the collection.
